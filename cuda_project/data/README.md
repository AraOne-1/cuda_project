Data generated at runtime. Download from: https://archive.ics.uci.edu/dataset/31/covertype
Place `covtype.data.gz` here or run `python scripts/prepare_data.py` to auto-download.
The binary dataset is deliberately not committed to Git (approx. 126 MB).
